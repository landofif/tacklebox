# Credits

Where tacklebox's ideas and data come from. Features are rebuilt from how these mods behave and from server facts; no code is copied from them (FOE+, FOE-R and FOECollab are AGPL). Each feature's own doc says the same in its "Credit" line.

| Who | What | Used for |
|---|---|---|
| **FOE+** by itshaxr (`github.com/itshaxr/FOE-Plus`, AGPL) | A fork of FOE-R with FOECollab and FishOnAutotip merged in | The ideas for the timers hud, dry streak chat messages, wrong pet and armor warning (and its pet per location table), mini event hud (and its timing), travel map and pet prices screen; the cosmetic store and vote facts |
| **FOE-R** by DannyPX | The mod FOE+ is built on | The base those features grew from |
| **FOECollab** by Kimberlyow (AGPL) | The FishOnMC companion mod tacklebox can run next to | The small capitals look of labels, its catch hook and config as an API reference (`foecollab/index.md`), server facts found through it (codepoints, NBT keys, chat lines), the first versions of the pet, armor and dry streak warnings |
| **The FishOnMC community's pet price sheet** (`docs.google.com/spreadsheets/d/1mmOt9-hvCfT3flCekELM7F3FcOrbygwKGOrNyLwA2dk`; no author named on it) | Player-to-player pet prices by rating and rarity | The pet prices screen, which shows it as written and names it |

Docs of the features above: `huds/timers.md`, `chat/dry-streaks.md`, `huds/gear-warning.md`, `huds/mini-event.md`, `menus/travel-map.md`, `menus/pet-prices.md`.

Also: `fishonmc-autofish` is a data source only (fonts and item facts, none of its automation), and the world tweaks came over from luna's own older fishutils mod (`display/world-and-totem.md`).
