# Fishonmc menu and presets

- fishonmc menu (`menu/FishMenu`, `menu/Locations`, `screen/FishMenuScreen`, setting `fishMenu`, `menuCells`): `MinecraftClientMixin` swaps a `GenericContainerScreen` for `FishMenuScreen` when its title is the main menu glyph string or the player just typed `/menu`, `/travel` or `/turbotravel` (the travel title is only art, so it is detected by command and by items). The screen reads the real chest slots, so it keeps working while the server refills them, and a click sends `ClickSlotC2SPacket` straight away with no client side pickup. Travel mode (4+ items named after a location) draws the menu item itself, scaled up, as the location picture, a `ui/Arc` ring for the level progress read from the tooltip by `FishMenu.info` (guesses: "level n", "n%", "a/b"; check against a real tooltip with `/tacklebox debug`), and the best place to fish (lowest level) plus the bait notes in `Locations`. Layout is saved per button in `menuCells`; the default for the main and other button menus is where the server put each button in the chest (so the main menu matches the wiki's fishing_menu picture: profile head on top, two rows of icons, help/close/settings/daily missions below), and travel is a 4 column grid. The wiki's fishing menu page says the fish compendium holds the location leveling info, so the level data may need reading from there too (use the F8 dump). The button-only menus (stats, quests, crew, and anything opened from inside our screen, such as the quest difficulty and tier pages) use the same screen; menus that need your inventory (sell, vault, tackle shop, pets, armor) stay as the chest. Shulker, concrete and terracotta buttons draw as flat colour squares (the idea of foecollab's `QuestMenuSquareHandler`, written fresh).
- Presets (`screen/PresetsScreen`, swapped in by `MinecraftClientMixin` when `FishMenu.isPresets`): wardrobe cards, armor presets draw an `OtherClientPlayerEntity` with the set via `InventoryScreen.drawEntity`, parts presets draw their items big; a click on a card sends the equip slot click. Rod part presets.

## Button look (2026-10-09, asked for by l)

`FishMenuScreen.drawTile` draws the buttons as square tiles filling their whole cell, so neighbours touch with no gaps (rounded corners left notches where four meet). The "menu background" (`display/MenuBackground`, `CORNER = 0`) has square corners too. Setting `menuAccent` ("accent buttons", menus group) fills the tiles with the accent gradient at `menuAccentOpacity` (5 to 100, default 40); the gradient runs left to right over the whole grid, not per button, and hover adds a 1 px gradient outline. Off = the dark grey fill. Not run in game yet.
