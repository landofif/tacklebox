# Vault overview

- Vault overview (2026-10-08; `menu/Vaults`, `screen/VaultScreen`, setting `vaultMenu`, "vaults" in the cloth tab): `MinecraftClientMixin` swaps any `Personal Vault #n` chest for one screen with all seven vaults and a search over them (matches outlined, the rest dimmed). The open vault and your inventory are live (slot clicks go through `interactionManager.clickSlot`, shift quick moves, the held stack follows the cursor), items get rarity circles, the layout with the biggest slots wins. Clicking another vault sends `/pv n` (a third exception to display only, asked for by l 2026-10-08, only on the player's own click). Only the 45 item slots count, the last row (red panes, Close, Next) is never shown. Vaults are only read when opened, so each is remembered when you open it (live while open, and when the chest view closes) in `config/tacklebox/vaults.nbt`, and unopened ones say "type /pv n to load". The chest view button gives the real chest back for moving items. Not run in game yet.
