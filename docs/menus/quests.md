# Quests

- Quest again marks (2026-10-30, asked for by luna; `menu/QuestRedo`, `HandledScreenMixin.questRedo`/`questClick`, chat in `Tacklebox`): in the plain /quests chest, after you click a quest, the difficulty menu marks the button that quest had (`EASY`/`MEDIUM`/`HARD`) and the tier menu marks its tier (`Adult` ... `Legendary`), each with a see-through green square behind the item like the /travel marks. Always on, no setting. Display only: nothing is clicked for you (no-automation rule).
  - How: while the quest list is drawn, each quest item's lore gives its number (name `Fishing Quest #3`, else its slot 12, 13, 14, 20 ... 24), its difficulty (`ʜᴀʀᴅ ꞯᴜᴇsᴛ`; the server's q is U+A7AF, not the `ǫ` in `Glyphs`, so only the first word is read) and its tier (`Catch 71x Rare fish`). They are kept per quest number for the session. Clicking a quest item picks that number. A slot that no longer says what it was (claimed) keeps the last thing seen there.
  - Fallback: the start chat line `QUEST » Started a new Hard fishing quest to catch 29x Epic at Cypress Lake` sets the last started quest and stores it for the picked number. With nothing known nothing is marked.
  - The quest list, difficulty menu and tier menu all have the same title (`U+EEE4 U+D539`, menu name `quests`), so the buttons are told apart by their lore: `Click to start a hard quest.` (difficulty) and `Click to start.` (tier). Slot numbers are not used for them (the difficulty menu's slot 13 is quest #2's slot in the list).
  - Lost on a game restart until the list has been opened once. Only in the vanilla chest; if `fishMenu` ever shows quests as tiles, the tiles get no mark.
  - Tests: `QuestRedoTest`, `QuestRedoIntegrationTest` (luna's dumps of 2026-10-29 23:55 to 23:58, both menus with every button). Not seen in game yet.
