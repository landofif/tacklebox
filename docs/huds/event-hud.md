# Event hud

- Event hud (2026-10-24, asked for by luna for the Halloween 2026 event; `hud/EventHud`, settings `eventHud/eventPos/eventScale/eventAlign`, "event" in the cloth tab, a mover box, drawn in the `custom_huds` element): text with a shadow and no box, like quests left. Off by default.
- Source: `/event`, a vanilla chest (title art only, `U+EEE4 U+D568`, so `EventHud.isEventMenu` looks for `U+D568`; `FishMenu` does not take it over). `XpEstimate.tick` calls `EventHud.scan` every half second for the open screen. Items read: `Threshold n` player heads (slots 10-16; lore `[<have> pts|<need> pts]`, then reward lines: money, items, a cosmetic, then a blank line and the bait package with a `┗ <biome>` line that is dropped; `<none>` means 0, `need` is the total points, not per step), the book `Event Missions → <n> pts` (slot 22), the leaderboard head (slot 41: `Your Placement: Unranked`, `Event Points: <n> pts`, refreshed by the server every 5 minutes) and the `Welcome to Halloween 2026!` gunpowder (slot 39, gives the hud title).
- Chat (luna's latest.log, 2026-10-24; the text is `Matcher.normalize`d, so the newlines are spaces): `<EVENT> EVENT MISSION [+50 pts]` then `🎣 <name>` (plus ` ✔` when done) then `┗ (5/10) [250 pts|50 pts] Partial`. After the name's bracket the mark is `Partial` (points per catch up to the limit, 10 here; a limited mission), `∞` (repeatable: `(0/10)` stays, the first number in the brackets is everything it gave so far, the second what one catch gives) or empty (one-time, `(1/1)`, 500 pts for a size goal like `Tiger Muskellunge ≥ 18lb`). `Heaviest Arapaima` is `┗ (pts = Weight) 50.86 pts`. `<EVENT> EVENT THRESHOLD tier up! [250 pts|220 pts]` is `[your total|threshold]`, followed by `Rewards:` and the reward lines as separate messages (ignored, the menu has them). The tier up comes before the mission line of the same catch and already counts its points, so a mission line within 1.5 s of a tier up is not added. A player quoting a line in chat has `name >` in front and does not match.
- Points: set by `/event` and by tier ups, and +N for each mission line in between (so the total drifts if a message is missed or `Heaviest Arapaima` gives a delta instead of the new best; opening `/event` fixes it).
- Missions: the book (slot 22, dumped 2026-10-24) lists all of them as `- 🎣 <name> [✔]` then `┗ (cur/max) [earned|per] mark` (or `┗ (pts = Weight) 50.86 pts`); `EventHud.read` replaces the saved missions with that list every time `/event` is open, chat lines then keep them current. The River Monsters variants have a pack glyph as tag (`U+F041..43` = albino, melanistic, trophy, in the menu's order; `gigantic` is text), spelled out in the name. A chat line for a variant may not match its book entry (not checked). The hud shows missions that are not done and the repeatable ones, except the albino/melanistic/trophy River Monsters and the heaviest arapaima (left out on luna's ask, still saved) (`∞` never counts as done); setting `eventMissions` (on). The old `eventFinished` setting is gone.
- Counters (2026-10-24, luna's log): the chat line of a repeatable mission always says `(0/100)`, so for `∞` the count of the book is kept and chat only moves the points. The location missions (`Amazon (40/1500)`) send no chat line for the count at all, so `EventHud.onCatch(location)` (called from `FoeCatch`, foecollab's location id mapped by `LevelBars.SHORT` to the book's name: amazon, danube, toledo, great lakes, murray) adds 1 per catch; opening `/event` corrects it. `Freshwater (13/100) ∞` is not counted by the mod (rule unknown: it gave 2 pts only on some catches), it only follows the book. Assumed: every catch at the location counts. Rows show the count: `6/100 10pts/2pts`.
- Colours: `scan` reads the colour of the first run with a letter on each lore line (`Item.colors`); a mission's name and the next threshold's reward lines are drawn in it (white when unknown), gold/brown ones (`brown()`: red high, blue low, red above green) and the values are drawn in bright green `55FF55` instead. Rows are `{label, value}` plus, for coloured ones, `{label argb, value argb}` as numbers.
- Saved: `TackleboxSettings.eventState` (`EventHud.State`, bound in `sanitize`), saved when the menu or a chat line changed it.
- Rows: points, the next threshold with points to go and its rewards, thresholds reached/total, placement, then the missions (`river monsters 24pts/2pts` (earned/per catch), limited `wels catfish 3/10 150pts/50pts`, one-time `amazon 40/1500 400pts`, `heaviest arapaima 50.86 pts`). When every threshold is reached it says so.
- Not tracked yet: the River Monster species and the event booster text (slot 37/39, static).
- Tests: `EventHudTest` (menu items and the log's chat lines in, rows out, Gson round trip). Not run in game yet.
