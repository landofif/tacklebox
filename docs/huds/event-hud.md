# Event hud

- Event hud (2026-10-24, asked for by luna for the Halloween 2026 event; `hud/EventHud`, settings `eventHud/eventPos/eventScale/eventAlign`, "event" in the cloth tab, a mover box, drawn in the `custom_huds` element): text with a shadow and no box, like quests left. Off by default.
- Source: `/event`, a vanilla chest (title art only, `U+EEE4 U+D568`, so `EventHud.isEventMenu` looks for `U+D568`; `FishMenu` does not take it over). `XpEstimate.tick` calls `EventHud.scan` every half second for the open screen. Items read: `Threshold n` player heads (slots 10-16; lore `[<have> pts|<need> pts]`, then reward lines: money, items, a cosmetic, then a blank line and the bait package with a `┗ <biome>` line that is dropped; `<none>` means 0, `need` is the total points, not per step), the book `Event Missions → <n> pts` (slot 22), the leaderboard head (slot 41: `Your Placement: Unranked`, `Event Points: <n> pts`, refreshed by the server every 5 minutes) and the `Welcome to Halloween 2026!` gunpowder (slot 39, gives the hud title).
- Chat (luna's latest.log, 2026-10-24; the text is `Matcher.normalize`d, so the newlines are spaces): `<EVENT> EVENT MISSION [+50 pts]` then `🎣 <name>` (plus ` ✔` when done) then `┗ (5/10) [250 pts|50 pts] Partial`. After the name's bracket the mark is `Partial` (points per catch up to the limit, 10 here; a limited mission), `∞` (repeatable: the line is sent when its cycle is full, 10 River Monsters or 100 Freshwater, so it always says `(0/10)` and the count starts again; the first number in the brackets is everything it gave so far, the second what one catch gives) or empty (one-time, `(1/1)`, 500 pts for a size goal like `Tiger Muskellunge ≥ 18lb`). `Heaviest Arapaima` is `┗ (pts = Weight) 50.86 pts`. `<EVENT> EVENT THRESHOLD tier up! [250 pts|220 pts]` is `[your total|threshold]`, followed by `Rewards:` and the reward lines as separate messages (ignored, the menu has them). The tier up comes before the mission line of the same catch and already counts its points, so a mission line within 1.5 s of a tier up is not added. A player quoting a line in chat has `name >` in front and does not match.
- Points: set by `/event` and by tier ups, and +N for each mission line in between (so the total drifts if a message is missed or `Heaviest Arapaima` gives a delta instead of the new best; opening `/event` fixes it).
- Missions: the book (slot 22, dumped 2026-10-24) lists all of them as `- 🎣 <name> [✔]` then `┗ (cur/max) [earned|per] mark` (or `┗ (pts = Weight) 50.86 pts`); `EventHud.read` replaces the saved missions with that list every time `/event` is open, chat lines then keep them current. The River Monsters variants have a pack glyph as tag (`U+F041..43` = albino, melanistic, trophy, in the menu's order; `gigantic` is text), spelled out in the name. A chat line for a variant may not match its book entry (not checked). The hud shows missions that are not done and the repeatable ones, except the albino/melanistic/trophy/gigantic River Monsters and the heaviest arapaima (left out on luna's ask, still saved) (`∞` never counts as done); setting `eventMissions` (on). The old `eventFinished` setting is gone.
- Counters (2026-10-24, luna's log): a repeatable mission sends its chat line only when the cycle is full (`Freshwater (0/100) [12 pts|2 pts] ∞`, `River Monsters (0/10)`), so the line sets the count to 0 (the first version kept the old count and Freshwater ran on to 111/100, luna's screenshot). Everything in between is counted per catch in `EventHud.onCatch(location, fishId, now)` (called from `FoeCatch`; foecollab's location id and fish id): +1 for the location's mission (`ServerInfo.LOCATIONS` maps the id to the book's name: `amazon river`, `danube river`, `toledo bend reservoir`, `great lakes`, `murray river`; the first version looked for `amazon`, `toledo` and so on and counted nothing), +1 for `Freshwater` at fresh water locations (`EventHud.FRESH`, from the research doc's table; the book went from 13 to 48 within a few hours of fishing), +1 for `River Monsters` for a catch of one of the species of the event (`RIVER_MONSTERS`, the species item of `/event`: piraiba, alligator gar, wels catfish, muskellunge, murray cod, golden dorado, flathead catfish, beluga sturgeon, tiger muskellunge, arapaima, electric eel; fish id compared letters only, any variant; luna: "when u catch any of these fish the river monster quest goes up by 1"). A repeatable count that reaches its max goes back to 0. The chat line of the catch that fills the cycle comes just before the catch (the log shows the line, then `[FoE] Tracking <fish>`), so a catch within 1.5 s of that line of the same mission is not counted (`cycleAt`; the other order, catch first, works too). Opening `/event` corrects every count. Assumed: every catch there counts, any variant of a river monster counts. Unverified: foecollab's `fishId` for those species (letters only should match `flathead_catfish` and `Flathead Catfish` alike). Rows show the count: `6/100 10pts/2pts`.
- Colours: `scan` reads the colour of the first run with a latin letter on each lore line (not any letter: the hangul art in front of every lore line is a letter too and brown `5C4B34`, which made every name brown on 2026-10-24) (`Item.colors`); a mission's name and the next threshold's reward lines are drawn in it (white when unknown), gold/brown ones (`brown()`: red high, blue low, red above green) and the values are drawn in bright green `55FF55` instead. Rows are `{label, value}` plus, for coloured ones, `{label argb, value argb}` as numbers.
- Saved: `TackleboxSettings.eventState` (`EventHud.State`, bound in `sanitize`), saved when the menu or a chat line changed it.
- Rows: points, the next threshold with points to go and its rewards, thresholds reached/total, placement, then the missions (`monsters 1/10 24pts/2pts` (count, earned/per catch), limited `wels catfish 3/10 150pts/50pts`, one-time `amazon 40/1500 400pts`). Labels are shortened on luna's ask (`EventHud.label`): a location by its short name from `LevelBars.SHORT` (`amazon`, `danube`, `toledo`, `great lakes`, `murray`), `river monsters` as `monsters`, `freshwater` as `fresh`; the saved missions keep the book's names. When every threshold is reached it says so.
- Not tracked yet: the event booster text (slot 39, static). The River Monster species list (slot 37) is hard coded.
- Tests: `EventHudTest` (menu items and the log's chat lines in, rows out, Gson round trip). Not run in game yet.
