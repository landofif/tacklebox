The picture behind the text is `config/tacklebox/hud.png` (in its own colours, cropped to cover, opacity slider; the cloth tab has an open folder button). Not run in game yet.

- Fish frenzy line (2026-10-18, asked for by luna from her cycle sheet; `hud/FrenzySchedule`, key `frenzy` after the moon line, on by default): a window opens every 3 hours at 01, 04, ... 22 o'clock Middle European time (`Europe/Berlin`, so it follows summer time; assumed, luna was not asked whether the server uses a fixed offset) and a frenzy can spawn in its first 2 hours, then lasts 1 hour from its own spawn, so it never runs into the next window. The line says `<place> <time left>` while the chat announced a frenzy (state kept by `BoostsHud`, `frenzyLeft`/`frenzyPlace`), else `spawn? <time>` (time to window close) inside the window, else `in <time>` (next window). A window that already had its frenzy (`BoostsHud.frenzySeen` inside it) shows `in <time>` too. Label is `Frenzy:` (shortened 2026-10-18). Whether every window gets a frenzy is unknown, hence "may spawn". `FrenzySchedule.describe` is pure (the server hud class cannot load in unit tests, its static init needs the Fabric loader). Tests: `FrenzyScheduleTest`, `FrenzyHudIntegrationTest`. Not run in game yet.
- Community goal lines (2026-10-18, asked for by luna; `hud/CommunityGoal`, keys `community` and `community mine` after the frenzy line, on by default, hidden while the bar is not up): the boss bar `Community Goal: 21.28K/100k Catches` (read in `ServerInfo.readBossBar`) is all players' catches; `Your Catches` is the mod's own count, +1 per catch from foecollab's catch hook (`FoeCatch`) while the bar was seen in the last 3 seconds. There is no reset on a lower goal value (luna 2026-10-19: the join-time `/communityevent` is enough; a rounding difference between bar 22.4K and chat 22.41K had zeroed the count). The `/communityevent` reply (two plain chat lines in luna's log, `Community Catches: 21.21K/100k`, `Your Catches Contribution: 304`) sets the count to the server's number. The mod sends `/communityevent` itself once per game start, 5 seconds after joining a FishOnMC server (luna asked for it; its reply stays visible in chat). Last goal and count are saved in settings (`communityCurrent/Goal/Mine`). The vanilla bar is left alone. The "short catches" button also shortens these. Tests: `CommunityGoalTest`.
