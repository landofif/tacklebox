# Chummer range ring (planned, not built)

- What luna wants (2026-10-16): find placed chummers in range and draw a circle for the range, built from scratch. FOECollab's chummer tracker looks and seems weird to her; her own foecollab config has its chummer hud and ring off (`showChummerHud=false`, `solidRangeBar=false`, `rangeRadius=20`).
- Range: 20 blocks horizontally, measured by luna from the centre (-1523.533 63 2018.497) to an edge (-1503.483 64 2018.643), 20.05 blocks. All new chummers have 20; some players still hold about year-old ones with 10 (the lore says `Range of 10 blocks`, `custom_data` has no range). Decision: assume 20.
- Item: `player_head`, `custom_data {bitespeed, rarity, timer:15.0f, type:"chummer"}`; bite speed by rarity 75, 130, 180, 250, 375. The server answers `Place the Chummer on a block.` when you use it off a block and refuses a second chummer nearby.
- What a placed chummer is in the world (skull block, armor stand, display entity) is not known yet. FOECollab never finds it: it takes the placer's name from the chat line, then the spot the placer is looking at (raycast 6 blocks, else their feet), so placers outside render distance are ignored. FOECollab draws a translucent wall 1 block tall (96 segments, `WorldRenderEvents.AFTER_ENTITIES`, `RenderLayers.debugQuads()`) and its own comments say the server draws a particle circle too.
- First step: `/tacklebox debug entities [radius]` (`DebugDump.entities`, default 24, max 64) dumps the crosshair target, every entity and every block entity around you to `config/tacklebox/guidump/entities-<time>.txt` and the clipboard: type, position, name, worn and held items with `custom_data` and skull profile, display entity contents, raw nbt. Look at the placed chummer and run it next to it. Not run in game yet.
- Drawing (checked by compiling against the build.3 jar, nothing run): a flat ring from translucent quads in `WorldRenderEvents.AFTER_ENTITIES` (`net.fabricmc.fabric.api.client.rendering.v1.world`), camera position from `ctx.worldState().cameraRenderState.pos`, vertices camera-relative, `ctx.consumers().getBuffer(RenderLayers.debugQuads())` (cull off, depth write off, so lift the ring a little off the ground). Vanilla's `GizmoDrawing.circle` also exists but is a 20-gon. The mod has no world-space drawing yet.
