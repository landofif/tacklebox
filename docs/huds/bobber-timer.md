# Bobber timer and bite hud

- Bobber timer (2026-10-08, asked for by l because foecollab's is disliked; `display/BobberTimer`, `screen/BobberScreen`, `/tacklebox bobber`, settings `timer*`/`bite*`): the timer is the own bobber's `age`, as a hud (`custom_huds`, mover box) and/or text over the bobber (projected to the screen and drawn in the hud, `BobberTimer.drawOverBobber`, because world text is flushed with the models and a hat covered it); the bite notification is a hud fed by the server's BITE! title (`InGameHudOverlayMixin.setTitle`, re-sends within 1.5 s are the same bite), with animation, duration, size, colour, shadow, text. `MinecraftClientMixin.doItemUse` marks the bobber as reeled on a right click with the rod, which hides the hud timer and the bite at once (the text over the bobber follows the bobber). The foecollab timer/bite title are left to be turned off in its own config. Not run in game yet.
