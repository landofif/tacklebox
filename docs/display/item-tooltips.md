# Short fish tooltips

- What it does (2026-10-16, asked for by luna; `display/FishTooltip`, setting `shortFishTooltips`, off by default, "short fish tooltips" in the menus page under "tooltips"): a caught fish's tooltip loses the scientific name, the separator under it, the value line and the ecosystem line, shows weight and length as one line `0.17lb/7.11in` (no labels, no kg or cm) and moves the rarity mark onto the name line. A Camouflage Grouper goes from 20 lines to 14. Display only: the item and its lore are never changed, only the list of lines the client draws, so foecollab (which reads `lore.get(15)`) is not affected.
- Hook: `ItemTooltipCallback` registered in `Tacklebox.onInitializeClient` in its own phase ordered after the default one, where foecollab registers. By then foecollab has swapped the rarity mark to its `foecollab:tags` font; the mark's segments are moved as they are, so it keeps that font. Only stacks whose `custom_data` has the `fish` key and not `shopitem` (`FishTooltip.isFish`) are touched, so compendium species items (cod with lore, no custom_data) are left alone.
- How it works: lines are found by label (`value:`, `ecosystem:`, `weight:`, `length:`, matched on `Glyphs.plain`) or by shape (the mark line holds only spaces and glyphs, the separator is blank and struck through, the scientific name is the unlabelled line under the mark), never by index. F3+H lines after the window stay. Every line keeps the server's window prefix, so a removed line takes its slice of the window with it. Line 0 (the plain item name) is never touched. A rule whose line is not found does nothing, and a tooltip with no window prefix is left alone. Running it twice changes nothing more. The `/` between weight and length has the colour of the weight number.
- Layout of the lore: `fishonmc-research.md`, section 5 ("Fish tooltip layout").
- Gotchas: the vanilla name line (0) and the window's first line (1) both show the name; luna's screenshot shows it once, so which one the pack hides is not known, and the mark goes on line 1. Only fish are done; bait, lures, rods and pets were not asked for and have no samples. Needs `/tacklebox debug item` (see `dev/build-and-debug.md`) to get a dump of anything new.
- Tests: `FishTooltipTest` (luna's real fish, each rule, mark font kept, variant glyph moves too, twice is the same, advanced lines stay, unknown layout left alone, `isFish`), `FishTooltipIntegrationTest` (old settings keep it off, saved switch round-trips). Not run in game yet: whether the window art shrinks cleanly, whether the mark sits on the visible name line, and a legendary fish.
